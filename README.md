# Final Project: News Explorer

**Intro**

News Explorer is an app that uses an API to render current news information based on keyword searches. Utilizing react, this news app is comprised of multiple components that allow the user to view multiple articles on a single topic.

**Technologies and Techniques Used**

- Figma
- React
- Vite
- Functional components, hooks
- CSS3 (flexbox, grid, media queries, psuedo classes,)
- BEM methodology
